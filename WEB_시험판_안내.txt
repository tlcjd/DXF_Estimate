DXF 견적프로그램 · 로컬 Chrome 시험판 (V0.24.12 기반 소스 사본)

실행
  1. 압축을 빈 폴더에 풀고 '웹_시험판_실행.bat'를 더블클릭합니다.
  2. 로컬 서버가 켜지고 Chrome/기본 브라우저에서 http://127.0.0.1:xxxx 가 열립니다.
  3. 오른쪽 '캐시 폴더'에 기존 프로그램 설치 폴더를 입력합니다.
      예: D:\P\Estimate\DXF_견적프로그램 작성
     '기존 프로젝트 캐시 검색'을 누르고 상단 '원본 캐시'에서 작업 도면을 고릅니다.
     두 번째 단계 원본 벡터 캐시(*.pkl)가 없으면 기존 프로그램에서 CAD 도서읽기를 먼저 합니다.
  4. 상단에서 층 변경 / 레이어 켜기 끄기 / GPU-CPU 렌더러 비교 / 선두께 / 원색-회색 등을 시험합니다.

특징
- 외부 인터넷 통신·설치·CDN 없음. 127.0.0.1(자기 PC)에만 바인딩.
- 기존 Python 엔진/캐시 자료구조 재사용. DXF 다시 변환하지 않음.
- 기존 원본 캐시, 프로젝트, CAD 파일은 읽기만 합니다. 수정/저장 안 함.
- 이번 시험은 원본 2단 캐시 벡터 비교용이며 3단 최적화 모드/수량산출/CAD 수정 반영은 미구현.
- 샘플 도면은 뷰어 UI 시험 전용으로 실제 CAD 도면 성능을 대변하지 않습니다.
- Ctrl+C로 종료합니다.
- Python 표준 라이브러리 기반이므로 웹 서버용 추가 패키지는 없습니다.
- 이 시험판 소스는 자체 포함되어 있습니다. 기존 프로젝트를 덮어쓰지 마세요.

참고
- .pkl 로딩은 Python pickle 특성상 신뢰할 수 있는 자신의 기존 프로그램 캐시만 사용하세요.
- 기존 프로그램의 *.pkl 백업/캐시와 같은 Python 환경에서 열어야 합니다.
- 도면 벡터는 변형 없는 레이어 색/좌표를 기준으로 표시하지만 CAD의 텍스트 폰트/채움/마스크 등의 완전한 픽셀 동일성은 아직 구현되지 않았습니다.
- WebGL2 미지원 시 Canvas2D로 자동 전환됩니다.

성능 표시의 ms는 JavaScript 프레임 준비·제출 시간입니다. 실제 GPU 완료시간/FPS와 같지 않습니다. 줌·팬 체감 비교에 참고하세요.
