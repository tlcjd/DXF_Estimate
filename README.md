# DXF 견적프로그램 로컬웹 시험판 V0.4

## 이번 변경: DXF 직접 읽기

- V0.3의 WebGL2/Canvas2D 도면 뷰어 및 검정/흰색 배경 유지
- 웹 상단에서 DXF 파일 선택 → [DXF 읽기] → 층별 화면 표시
- 이전 프로그램의 `app/rooms/core.py`(도곽/텍스트/블록/XCLIP/숨김 객체/벡터) 및
  `background_source_cache.py`(층별 분리)를 **필요한 의존성만** 가져와 재사용
- 기존 데스크톱 PySide6 실행부, CAD COM 연동 엔진, 전체 프로그램 UI 제외
- 층 도곽 인식 실패 시 `전체` 도면 표시
- 기존 캐시 찾아서 열기 기능도 유지
- DXF는 브라우저에서 로컬 Python으로 보내고 임시 복사본에서 읽습니다. 기존 DXF는 수정하지 않습니다.

## 실행 방법

1. **기존 프로그램에 덮어쓰지 말고** V0.4를 별도 폴더에 압축 해제하세요. V0.3 시험판 폴더에 덮어써도 됩니다.
2. `웹_시험판_실행.bat` 실행 → Chrome/Edge가 열립니다.
3. 웹 상단 `DXF 파일 선택` → 로컬 .dxf 지정 → `DXF 읽기`.
4. 분석 완료 후 상단 `도면 / 캐시`가 `DXF 직접읽기`로 바뀌며 층 목록이 표시됩니다.
5. 검정/흰색, 원색/회색, 레이어, 확대/이동, 객체 클릭을 확인하세요.

## 의존성

- Python 3.10+와 `ezdxf` 필요 (기존 프로그램의 Python `.venv`에 설치되어 있다면 재사용)
- 설치 필요 시: `python -m pip install ezdxf`
- 웹 JS/CSS는 로컬에 있으며, 사용 중 인터넷이 필요하지 않습니다.
- **PySide6는 필요 없습니다.**

## 현재 한계

- DXF 직접 읽기만 지원; DWG 및 현재 CAD COM 실시간 연동은 다음 단계입니다.
- **내용이 비어 있는 외부참조/XREF 블록은 이 단계에서 복원되지 않습니다.** CAD에서 XREF 바인딩하거나
  내용이 포함된 DXF로 내보내야 합니다. 진단에 빈 블록명이 표시됩니다.
- 별도 CAD 표에서 텍스트를 조합하는 창호 부호 읽기, 실/마감 수량 수정·프로젝트 저장은 미구현입니다.
- 지금 DXF를 읽은 결과는 **서버 메모리에만 보관**되며 프로그램 종료 후 남지 않습니다. 기존 캐시는 변경하지 않습니다.
- 파일 업로드는 최대 300MB, 층당 최대 선분 200만 개(시험용 안전 제한)입니다.
- 외부에서 받은 낯선 .pkl 파일은 열지 마세요. 기존 캐시 열기는 신뢰하는 자기 PC의 pickle만 사용하세요.
