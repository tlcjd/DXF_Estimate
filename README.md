## V0.5.6 — 미지정 도곽 자동탐색 / 혼재 도면 / 다른 도곽 선택

V0.5.5 기능은 모두 유지합니다. 기존 사용자 DXF, CAD, 원본 프로젝트는 수정하지 않습니다.

### 주요 변경

- **지정이 0개인 DXF:** 평면도 TEXT/MTEXT 제목과 닫힌 사각 폴리선·LINE 4개를 매칭해서 B2F, B1F, 1F, 4~20F, RF, PHR 등의 층별 도곽을 자동 제안합니다.
- **일부만 지정된 DXF:** 수동 지정 도곽을 기본 유지하고, 아직 없는 층의 도곽을 추가 인식합니다.
- **도곽선 자체가 없는 도면:** 같은 줄에 규칙적으로 배치된 평면도 제목 3개 이상에서 가상 도곽을 생성합니다. 화면에 `추정·확인필요`로 표시하므로 실제 경계 확인이 필요합니다.
- **같은 층이 여러 번 나오는 도면:** 중복을 오류로 버리지 않고 기본으로 표시할 도면 1개와 **다른 위치의 후보 도곽**을 각각 보관합니다. 서로 다른 도면의 형상을 한 층에 자동 합치지 않습니다.
- **도곽 판정 결과:** 기존 도곽, 자동 추가, 다른 도면 후보, 보류 사유, 사용자 확정을 분리해서 표시합니다.
- **`이 도곽 선택`:** 다른 도면 후보로 해당 층 도곽을 지정하고 다시 분석·캐시 생성합니다. `자동으로 복귀`로 사용자 선택을 해제할 수 있습니다.
- **지붕 평면도 = RF, 옥탑지붕 평면도 = PHR** 인식 보완. `창호평면도`, `KEY PLAN`, 일반 주석의 `평면도` 단어는 평면 제목으로 오인하지 않도록 개선했습니다.
- **캐시 버전 6 → 7:** 자동인식 알고리즘이 달라 기존 DXF는 최초 한 번 재분석합니다. 이후에는 층별 바이너리 캐시 재사용.
- 기존 Chrome/Edge 독립창, WebGL/Canvas, 흰색 배경, DXF 읽기, 강제 재분석, 로그 복사/TXT, 기존 캐시 삭제 유지.

### 실행/검사

1. **기존 로컬 웹 시험판 V0.5.5 폴더에 덮어쓰기** 후 `웹_시험판_실행.bat` 실행. 원본 데스크톱 견적프로그램 폴더에는 덮어쓰지 마세요.
2. 실제 DXF를 `DXF 읽기` 또는 `PC 경로 열기`로 1회 분석. 첫 읽기는 기존 캐시 버전 변경으로 재분석됩니다.
3. 층 목록을 확인하고 **`도곽 판정 결과`** 버튼에서 인식된 위치·근거·추정 여부를 확인합니다.
4. 동일 층의 다른 도면이 있으면 `이 도곽 선택`을 눌러 해당 영역으로 재분석할 수 있습니다. 강제 재분석 시 이전 정상 캐시는 성공 전까지 보존합니다.
5. 도곽 후보를 확정한 뒤에도 표시가 잘렸다면 로그 복사/TXT 저장으로 결과를 전달해 주세요.

**주의:** 화면에서 표시하기 위한 *자동/가상 도곽*은 견적 수량의 확정 경계가 아닙니다. 특히 `추정·확인필요`는 화면의 외곽이 맞는지 반드시 검토해야 합니다. 다른 도면을 사용자가 선택하면 원본 DXF를 재분석하는 시간이 다시 소요됩니다. 최초 대용량 DXF 해석의 메모리 최적화는 이번 버전에 포함되지 않습니다.

## V0.5.3: 평면도 도곽·층명 자동인식

### 자동 인식 규칙

1. 기존 `--■ DXF_공통_도면구분` 레이어에 지정된 도곽/층명은 최우선 사용합니다.
2. 도곽 지정이 없거나 일부 누락된 경우 DXF의 **닫힌 직사각형 LWPOLYLINE/POLYLINE**, 또는 **4개의 LINE으로 구성된 사각 도곽**을 찾습니다.
3. 도곽 내부 또는 가까운 위치의 `B3F 평면도`, `지하3층 평면도`, `1층 평면도`, `2~5F 평면도`, `PLAN` + 주변 `1F` 같은 **TEXT/MTEXT 제목**으로 층을 판정합니다.
4. 층명이 확인되는 도곽만 층별 캐시로 분리하며, 제목과 벽체/실내 박스가 혼동되지 않도록 작은 제목 박스를 제외합니다.
5. 동명이층 등 서로 다른 도곽이 같은 층으로 중복 잡히거나, 층명이 없는 경우에는 **판정 보류**합니다. 임의 층 추정은 하지 않습니다.
6. 화면의 **도곽 판정 결과** 버튼에서 기존 지정, 자동인식, 미확정 원인을 확인합니다. 아직 수동 도곽 편집 UI는 포함하지 않았습니다.

### 실행 및 확인

1. 기존 **웹시험판 V0.5.2 폴더**에 덮어씌우거나 새 폴더에서 `웹_시험판_실행.bat` 실행.
2. `DXF 파일 선택` → `DXF 읽기` 또는 대용량 DXF는 전체 경로로 `경로 열기`.
3. 층 목록에서 B3F/1F/... 자동 분류 확인.
4. `도곽 판정 결과` 버튼으로 인식 근거/미판정 항목 확인.
5. 선택한 층의 선분만 표시되고, 앱 재실행 시 층별 디스크 캐시가 재사용되는지 확인.

도곽 자체가 없는 도면, 이미지·블록 내부에만 제목이 있는 도면, 실제 층 명칭이 없는 도면은 자동으로 층을 판정할 수 없습니다. 이 경우 기존의 공간영역 분할 방식을 유지합니다. 정확도는 실제 현장 DXF로 검증해야 합니다.

## V0.5.5: 재분석 강제 실행 / 현재 DXF 캐시 삭제

- DXF 읽기 옆 **강제 재분석** 체크박스: 캐시가 있더라도 원본 DXF를 새로 분석하고 도곽 자동판정부터 다시 수행합니다. 파일 업로드와 PC 경로 직접 열기 모두 적용됩니다.
- 성공하면 선택된 DXF 캐시를 새 분석 결과로 교체합니다. 분석 실패 시 기존 캐시를 그대로 보존합니다.
- **현재 캐시 삭제**: 화면에 선택된 DXF (`direct`)의 층별 디스크 캐시만 삭제합니다. 클릭 후 확인창이 나타납니다. 다른 프로젝트의 캐시, 기존 `.pkl`, 원본 DXF는 삭제하지 않습니다.
- 현재 캐시를 삭제한 뒤 같은 DXF를 다시 열면 최초 분석부터 실행됩니다.
- 캐시 버전은 그대로 6입니다. 기존 캐시를 계속 쓰고 싶으면 체크를 해제한 채 기존처럼 열면 됩니다.
