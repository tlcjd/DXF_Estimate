# DXF 견적프로그램 로컬 웹시험판 V0.5.3

## V0.5.3: 평면도 도곽·층명 자동인식

기존 V0.5.2의 **DXF 직접 읽기 / 층별 디스크 캐시 / WebGL2·Canvas2D / 흰색 배경 / 독립 Chrome 앱창**을 그대로 유지합니다.

### 자동 인식 규칙

1. 기존 `--■ DXF_공통_도면구분` 레이어에 지정된 도곽/층명은 최우선 사용합니다.
2. 도곽 지정이 없거나 일부 누락된 경우 DXF의 **닫힌 직사각형 LWPOLYLINE/POLYLINE**, 또는 **4개의 LINE으로 구성된 사각 도곽**을 찾습니다.
3. 도곽 내부 또는 가까운 위치의 `B3F 평면도`, `지하3층 평면도`, `1층 평면도`, `2~5F 평면도`, `PLAN` + 주변 `1F` 같은 **TEXT/MTEXT 제목**으로 층을 판정합니다.
4. 층명이 확인되는 도곽만 층별 캐시로 분리하며, 제목과 벽체/실내 박스가 혼동되지 않도록 작은 제목 박스를 제외합니다.
5. 동명이층 등 서로 다른 도곽이 같은 층으로 중복 잡히거나, 층명이 없는 경우에는 **판정 보류**합니다. 임의 층 추정은 하지 않습니다.
6. 화면의 **도곽 판정 결과** 버튼에서 기존 지정, 자동인식, 미확정 원인을 확인합니다. 아직 수동 도곽 편집 UI는 포함하지 않았습니다.

### 실행 및 확인

1. 기존 **웹시험판 V0.5.2 폴더**에 덮어씌우거나 새 폴더에서 `웹_시험판_실행.bat` 실행.
2. `DXF 파일 선택` → `DXF 읽기` 또는 대용량 DXF는 전체 경로로 `경로 열기`.
3. 층 목록에서 B3F/1F/... 자동 분류 확인.
4. `도곽 판정 결과` 버튼으로 인식 근거/미판정 항목 확인.
5. 선택한 층의 선분만 표시되고, 앱 재실행 시 층별 디스크 캐시가 재사용되는지 확인.

**중요:** 자동인식 로직 변경에 맞춰 캐시 버전을 5 → 6으로 올렸습니다. 따라서 **V0.5.2에서 만든 DXF 캐시는 최초 1회 재분석**됩니다. 이후에는 디스크 캐시 재사용이 정상 작동합니다. 기존 사용자 DXF/프로젝트는 수정하지 않습니다.

도곽 자체가 없는 도면, 이미지·블록 내부에만 제목이 있는 도면, 실제 층 명칭이 없는 도면은 자동으로 층을 판정할 수 없습니다. 이 경우 기존의 공간영역 분할 방식을 유지합니다. 정확도는 실제 현장 DXF로 검증해야 합니다.

### 주요 파일

- `web_trial/auto_frames.py` — 자동 도곽/층명 후보 검출 (이번 버전 추가)
- `web_trial/server.py` — 기존 DXF 해석 엔진 연결, 결과 조회 API
- `web_trial/disk_cache.py` — 층별 저장 및 재실행 캐시
- `web_trial/static/` — 로컬 웹 도면뷰어와 도곽 진단 UI
- `app/rooms/core.py` — 기존 DXF/블록/XCLIP 해석 핵심 코드 재사용

### 테스트

```sh
python web_trial/test_auto_frames.py
python web_trial/test_dxf_import.py
python web_trial/test_large_cache.py
python -m unittest web_trial.test_browser_window
```

검증: 지정 레이어가 없는 폴리선 도곽·4 LINE 도곽, 분리된 `PLAN`/`1F`, 미분류 도곽 제외, 기존 전용 레이어 우선, 디스크 캐시 저장·복원, HTTP 도곽 진단·층 API, 24만 선분 대체분할. Windows Chrome 실제 화면에서 자동 도곽 검사 결과 UI 및 실제 287만 선분 DXF 성능은 별도 검증 필요.

## V0.5.4: DXF 읽기 진단 로그 복사 / TXT 저장

- `로그 복사`: 최근 DXF 읽기의 시작부터 종료(또는 실패)까지 기록을 클립보드에 복사합니다.
- `TXT 저장`: 동일한 기록을 `DXF_Read_Log_YYYYMMDD_HHMMSS.txt` (UTF-8 BOM)로 내려받습니다.
- 진행 단계별 경과 초, DXF 파일 경로, 캐시 재사용 여부, 분석 원본 선분 수, 층별 선·문자·채움 수, 도곽 자동판정 및 보류 사유, 빈 블록/XREF 경고, 실패 시 Python traceback을 기록합니다.
- 로컬 로그 파일: `web_trial/data/last_dxf_read.txt`에 최신 읽기 기록을 자동 보관합니다. 재실행 후에도 최근 로그를 열 수 있습니다.
- 기존 V0.5.3 캐시 형식과 호환됩니다. 캐시 버전은 변경하지 않아 DXF 재분석이 필요 없습니다. 다만 V0.5.3에서 이미 끝난 읽기 작업의 과거 진행 기록은 소급 생성할 수 없으므로 새 로그를 보려면 V0.5.4에서 한 번 읽기 작업을 실행해야 합니다(캐시 재사용도 기록됩니다).

## V0.5.4 UI 정리

- 상단 영역을 4줄 → 3줄로 줄여 도면 표시 영역 확대 (도면/층 선택을 헤더로, 보기 도구를 도면 상단 바로 이동, 렌더 수치는 하단 상태바로 이동)
- 색상·버튼·입력창 스타일 통일, SVG 아이콘 적용, 레이어 목록에 실제 레이어 색상 표시
- DXF 분석 중 진행률 막대 표시, Esc로 대화상자 닫기, 창 폭에 따라 버튼 자동 축소
- 버그 수정: `원색/회색` 버튼 클릭 시 스크립트 오류로 전환되지 않던 문제
- 서버·캐시·DXF 해석 로직은 변경 없음 (`web_trial/static/` 3개 파일만 수정)
