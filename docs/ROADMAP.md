## 1. 원본 프로그램 개요

PySide6 데스크톱 앱(약 4.3만 줄) + ZWCAD COM 연동. 최종 흐름:

> CAD 작성 → CAD/DXF 읽기 → 도면·층·실·부재 구조화 → 마감 지정 → 수량산출 → 내역·단가 → Excel·견적서 → CAD 역반영

## 3. 다음 작업 순서 (권장)

원칙: 읽기 전용으로 **보여주기 → 웹 데이터로 편집 → 산출 → 출력 → CAD 반영** 순서. 각 단계가 끝나면 바로 써볼 수 있게.

### 1단계 · 실 읽기 연결 (다음 작업)
- 서버: DXF 분석 때 `read_rooms()`를 함께 실행해 층별 실 데이터를 캐시에 저장(`rooms.json`), API `/api/rooms?floor=`.
  레이어 규칙은 원본 `settings.ini`의 값을 기본으로 읽음. 캐시 형식 추가이므로 `CACHE_VERSION` 처리 필요(또는 실 데이터만 별도 파일·지연 생성).
- 화면: 오른쪽 또는 왼쪽에 **실 목록**(층별: 번호·실명·순면적·둘레·공제·적용층×개소), 도면 위 **실 경계 오버레이 + 실명 라벨**,
  목록 클릭 ↔ 도면 강조 연동, **오류·확인사항 목록**(클릭하면 해당 위치로 이동).
- 층 이름 규칙이 도곽 자동인식(웹)과 원본 `read_drawing_divisions`가 다를 수 있으니 층 매칭 확인 필요.

### 2단계 · 프로젝트 저장
- 웹판 프로젝트 폴더(도면 + 실 데이터 + 편집 내용) 저장/열기, 자동저장.
- 원본 `사용자파일/프로젝트/*/project.json` 읽기(가져오기) 호환. 원본 파일은 수정하지 않음.

### 3단계 · 실 정보 편집 (웹 데이터만, DXF는 그대로)
- 실명·실번호·실구분·천정고 편집, 번호 자동기입(현재층/전층), 층 목록 일괄편집.

### 4단계 · 재료마감
- 재료마감 마스터(`재료마감_리스트.json` 가져오기, 복합재료·공종·단위).
- 실별 바닥/벽/천정 마감 지정, 마감그룹, 산식(A=면적, L=벽길이 등) → 실별 수량.

### 5단계 · 집계와 Excel 출력
- 층별·실별·재료별 수량 집계, 반복층 개소 곱, 할증, Excel 내보내기.

### 6단계 · 창호
- 창호 마스터, 평면 창호 읽기(원본 `rooms/widget.py` 창호 읽기·`window_tab.py`), 층별 개수, 벽마감 개구부 공제.

### 7단계 · 개요 · 기타 탭

### 나중 (장기)

- 입면·구조(원본도 미구현).

- 최초 DXF 읽기 메모리 피크 감소 (287만 선분급)

## 4. 전환 시 지킬 원본 규칙 (작성요령 발췌)
- 원본 DWG/DXF에 Save/SaveAs/Export/WBLOCK 금지. 결과는 캐시·프로젝트 폴더에만.
- 반복층(4~20F)은 실을 복제하지 않고 대표층 1개 + 적용층·개소(`repeat_count`)로 저장. 산출 수량에만 개소를 곱함.
- 실명 문자열에 층범위·개소를 섞지 않음.
- 산식 우선순위: 개별 재료 산식 > 그룹 산식 > 공란. 산식이 없으면 면적·길이를 자동 대입하지 않고 0.
- 층 정렬: 깊은 지하층 → B1F → 1F → … → RF → PH → PHR.
- 오래 걸리는 작업은 단계별 진행 로그(현재/전체) 표시.
